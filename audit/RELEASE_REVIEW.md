# paper-mirror · 译镜发布审查

审查日期：2026-10-09。本轮以 GitHub 源码发布为目标，检查模型接入、配置与缓存、既有阅读交互、图注恢复、笔记和导出、安装入口、公开文件及本地 Git 历史。没有使用用户文献执行翻译测试，也没有变更用户数据库。

## 已处理的问题

1. 视觉服务请求原先直接嵌在区域路由，难以替换协议。抽出 `VisionModel` 和默认传输实现；区域裁剪与业务流程继续共用。
2. 文本、OCR、版面检测缺少一致的注册入口。增加四类类型约定、可信本机注册钩子和适配器目录 API；保留默认实现、旧设置与离线 Mock。
3. 更换适配器可能复用同模型名称下的片段缓存。文本缓存加入适配器名称，图片缓存加入 OCR 适配器名称；翻译记忆仍按原文、语言和术语表复用。
4. 服务扩展的调用边界和坐标约定不明确。新增模型接入指南与合同测试，验证独立视觉调用、不启动 OCR、按需模型加载、部分翻译失败和旧设置兼容。
5. 发布名称与接入文档缺失。统一界面、PWA、README 和 API 标题为 paper-mirror · 译镜，补齐模型指南、贡献入口和问题反馈模板；公开截图来自隔离生成样例。

## 发布边界

- 当前定位为本机单用户阅读器，保留局域网配对保护。没有验证公网多用户部署。
- 新接口已使用离线替身验证，未宣称已适配或评测所有第三方模型。非 OpenAI 兼容服务需实现和注册适配器，权重和 SDK 不会自动下载。
- Windows 已完成本机验证；Windows/Linux CI 已配置，但本轮没有云端工作流运行结果，也没有 macOS 实机结果。
- 不包含真实服务质量评测、Python 包的在线漏洞审计、超大文献压力测试或完整扫描件批量识别验证。
- 自有源码许可与第三方说明保持原样；包含 AGPL 依赖的分发仍按已有第三方许可说明处理。
- 仓库尚未配置远程地址，本轮准备源码和本地提交，未推送 GitHub。

建议 GitHub 仓库名：`paper-mirror`。名称表达原文与译文的对照映射；未进行商标或名称占用核验。
