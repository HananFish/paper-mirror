## 图注识别与翻译追加修复

- 核实当前链路：DocLayout-YOLO/YOLOv10（DocStructBench 1024 权重）检测版面；优先读取 PDF 原生文字，位图用 RapidOCR 的 PP-OCRv4 det/rec 和 mobile v2 方向分类；普通翻译服务当前配置为 `hy-mt2`，手动视觉识别配置为 `qwen2.5vl:7b`，配置不代表视觉服务已经启动。
- 现有文档无 caption 块，旧解析遗漏的图注不会随代码升级自动出现。全文翻译时离线补回原生图注；图片翻译时补回当前页图注，并对缺少文字层的检测图注区域使用 OCR。不重建现有段落，保留 ID、译文、笔记和批注锚点。
- 图片操作同时翻译图片框外的关联图注，按未旋转的版面匹配最近图片并排除表注；成功图注译文按模型、术语及语言指纹复用，重复点击不重复提交相同图注。统一单段翻译的强制术语过滤。
- 合并同一行的加粗编号和普通说明后再分类，支持补充材料 `Fig. S.1` 等编号；保护边缘图注编号。纯位图图注按视觉行和横向位置排列 OCR 片段，避免把编号放到 Figure 前面；低置信度片段不自动翻译。
- 验证：13 项文档语义回归（含真实 RapidOCR 图片图注、旧文档补全幂等、90 度旧坐标图片关联、译文与笔记保留、Markdown 导出）、38 项后端回归、23 项 Edge 浏览器检查、前端构建与 Python 编译通过。在现有四份文档数据库的隔离副本补回 36 条图注，第二次补全均为 0；未更改用户原库或调用真实翻译/视觉服务。
- 更新并重启应用后，再次执行“翻译图片及图注”或全文翻译即可补全旧文档，无需重解析。纯位图图注仍依赖版面检测能定位图注区域，严重模糊或未检测到的图注可用框选 OCR/视觉识别校对。

## 鼠标文字划选追加优化

- 左键拖选按行定位最近字符端点，使用 PointerEvent 小数坐标避免小字号句末标点因坐标取整而漏选，支持正向/反向拖动、行间空隙吸附、边缘自动滚动及页面外松开鼠标；保留双击选词、三击选段落和带修饰键的原生操作。
- 文字层按真实位置识别双栏和跨栏分带，整理 PDF 内部交错的文字顺序；普通拖选限制在起始栏和分带中，减少邻栏被带入。定位按未缩放文字层尺寸换算，缩放无需重建文字层。
- 高亮只收集实际选中的文字节点矩形，排除换行和容器产生的空白范围；多行摘录补齐英文词间空格，按矩形交叠面积关联段落，减少中心点落在空白处时误挂接。
- 段落操作卡片原来的全页透明遮罩会拦截后续拖选或双击。改为监听卡片外的按下事件关闭卡片，鼠标操作继续进入正文；补齐图表注释的段落操作类型。
- 验证：23 项 Edge 浏览器检查和 TypeScript/Vite 构建通过；新增真实鼠标完整句子正向/反向拖选、双击选词、交错双栏拖选及页面外松开后保存的文字/矩形检查。已有独立高亮、缩放复用、图注、笔记与 PDF 下载回归仍通过。未进行各种复杂 PDF 字形与硬件性能的覆盖性基准测试。

## 标题样式、图表注释与参考文献追加修复

- 解析保留主导粗体、字号、行数和对齐方式，识别与正文同字号的加粗副标题；局部加粗的图注标签不会使整段加粗。译文标题保留源字号与字重，按源对齐方式显示，仅使用下一块前的空白换行，空间不足时可在标题框内滚动查看。
- 图注、表注和表格脚注独立生成 `caption` 块，纳入正文翻译、覆盖显示与 Markdown 导出。版面检测不再把图注并入图形、不再过滤表格脚注；启发式路径优先提取图注续行和表格下方 Note/Source 注释，防止被图形膨胀范围吸收。
- 参考文献章节标记为 `reference`，跨页保持原文、跳过批量和单段翻译；识别其后的附录/补充正文并恢复翻译。旧参考文献译文在阅读界面隐藏，Markdown 保留参考文献原文，进度统计排除已分类的参考文献译文。
- 旧解析数据通过按页缓存的原文文字信息恢复标题样式，并兼容误分成列表的加粗副标题；阅读接口使用临时分类，不写入数据库。全文翻译时持久化参考文献分类。旧版已被丢弃的图表注释须重新解析恢复。
- 验证：38 项既有后端回归、8 项新增文档语义回归、20 项 Edge 浏览器检查、TypeScript/Vite 构建通过。覆盖两种版面解析路径、主副标题和非粗体标题、局部粗体图注、跨页参考文献/附录、旧数据显示及 Markdown；浏览器实际核对标题字号、字重、对齐和图注显示，已检查标题/图注截图。使用临时生成文档和离线模型替身，不调用真实云服务。

## 图片翻译与校对追加优化

- 图形区域优先读取 PDF 自带文字，扫描图使用 RapidOCR；提高默认渲染精度至 240 DPI，限制裁剪像素，保留识别置信度，合并原生文字与 OCR 时去除重叠结果。修正非整数裁剪原点和旧版旋转图片坐标；OCR 实例初始化和识别加锁。
- 相邻图表标签保持独立，只保守合并连续长句。结合附近图注和术语表批量翻译；数字、常见单位、短缩写和公式保留原文，低置信度项目提示校对。部分失败保留成功译文和原文，显示进度；批量再次执行复用成功结果，模型、目标语言、协议、服务地址、术语或上下文变化后重新处理。
- 译文限制在原文字框内，避免扩展覆盖图表邻近区域；完整内容可悬停查看。图片增加“校对 / 视觉识别”入口，带入已识别文字和译文，支持本地重新识别、修改文本后翻译、更新裁剪、主动选择视觉模型处理复杂表格。
- 区域识别统一使用已安装的 RapidOCR，避免依赖未安装的 Tesseract；手动校正文本不再重复 OCR，视觉请求不先做本地识别，截断或过滤结果显示错误。裁剪改变或关闭弹窗时取消前端旧请求，防止过期结果覆盖草稿。
- 区域翻译保存后立即刷新笔记与批注；部分保存失败后重试、修改后再次保存复用已创建记录，避免重复生成笔记。校对正文通过现有中文附录进入批注 PDF。
- 验证：38 项后端回归、19 项 Edge 浏览器检查、TypeScript/Vite 生产构建和差异空白检查通过。真实本地 RapidOCR 识别了生成的图片标签和公式；浏览器完整验证识别结果刷新、公式不覆盖、校正文本翻译、部分保存失败重试及 PDF 中的校对正文。测试使用隔离数据和离线翻译替身，没有调用真实云端翻译或视觉模型。
- 普通图中文字建议本地识别后校对；复杂表格、流程图通过视觉入口保留结构。当前保留公式依靠启发式，不是数学公式专用识别器；真实论文图片和所配置视觉模型的准确率仍需结合具体材料核对。

- 阅读器补充无矩形页批注的页边入口和编辑弹窗，不再因为缺少选区坐标而无法显示或编辑。

## 缩放、视图切换与笔记可见性追加修复
