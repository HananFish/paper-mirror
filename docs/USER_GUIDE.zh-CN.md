# paper-mirror · 译镜使用手册

应用界面使用中文；[PDF 说明书](UserGuide.pdf) 使用英文，既是操作手册，也是翻译和批注的练习文献。

## 1. 开始使用

运行安装与启动命令后，访问 http://127.0.0.1:8000。点击首页“使用指南”可直接导入练习文献，重复点击会按内容去重；“下载说明书”可以保存原始 PDF。

首页标语“万卷皆如原文”上的墨滴随鼠标移动，圈内文字呈现金色；移开恢复。手机上点击可开关效果，键盘聚焦后按 Enter 或空格也可切换，Escape 关闭。点击“文献书库”向下浏览列表。系统启用“减少动态效果”时，墨水背景静止。文献右侧的“…”菜单提供重新解析和删除操作。

拖入自己的 PDF 或点击“导入 PDF”，等待解析完成。默认 Mock 只演示翻译流程，需在设置里配置真实文本翻译服务后才能生成真实译文。详见 [安装与配置](INSTALL.md)。

## 2. 阅读与文字选择

原文栏和译文栏使用同一份 PDF，支持双栏、仅原文和仅译文。译文覆盖在原段落位置，图片、表格结构和公式保留。翻译膨胀时字号会自适应，重要公式和数字请与原文核对。

按住左键从句子的第一个字符拖到最后一个字符，支持反向拖选；普通拖选限制在起始栏，减少选中邻栏内容。双击选词、三击选段；拖到视口边缘可自动滚动。点击段落可复制原文、译文或重译此段。

目录按检测到的标题导航。Ctrl+F 检索当前文献的原文和译文；文献库搜索框输入关键词后回车，搜索全部文献。

| 快捷键 | 作用 |
| --- | --- |
| J / K | 下一页／上一页 |
| + / - / 0 | 放大／缩小／适应宽度 |
| 1 / 2 / 3 | 双栏／原文／译文 |
| Ctrl+F | 页内搜索 |
| ? | 查看快捷键 |

输入框编辑时不会触发翻页等快捷键。

## 3. 图片、图注与表注

在译文栏的图片上点击“翻译图片及图注”。应用优先读取 PDF 文字层，图片部分使用本地 OCR，然后调用文本翻译服务翻译标签；图片框外关联的图注也会一并处理。

旧文档没有独立图注块时，打开阅读器会自动补回原生图注，无需重新解析；点击图片翻译或“继续翻译”可翻译新增图注。图片下方单独显示图注完成数，失败可点击重试。纯位图图注依赖版面检测定位；未定位或模糊的文字可框选 OCR，也可使用独立的“视觉识别”服务。识别不确定的内容应校对，数字和公式不要仅凭译文判断。

图片按钮按显示宽度调整，缩放时保持可读，小图使用简短文字。点击“显示原文”可隐藏图内译文，再点击“显示译文”恢复。“重新识别”默认使用本地 OCR，也可选择设置中已配置的视觉模型；视觉模型会接收裁剪图，结果在校对窗口显示，可保存到笔记与区域批注。

表格标题和注释可以翻译；表格单元格与结构的完整翻译尚未提供。参考文献条目保留原文，之后的附录正文仍可翻译。

## 4. 高亮、附注与阅读笔记

放大后可点击工具栏的箭头图标切换到手形工具，再按住左键拖动查看任意区域；按 H 切换回来。箭头表示文字选取，手掌表示平移。按住空格加左键、或直接按住鼠标中键，也可临时平移。双栏模式下两个方向的滚动都同步。

常用快捷键：Ctrl+滚轮以鼠标位置为中心缩放 PDF；Ctrl++／Ctrl+-／Ctrl+0 放大、缩小、适应宽度；PageDown／PageUp 翻页；Ctrl+Home／Ctrl+End 跳到首页、末页。普通左键继续用于文字选取，Shift+拖动仍用于区域识别，提示集中在工具栏的问号帮助图标中。点击缩放百分比也可适应宽度。图片 OCR 在图内的“翻译图片及图注”入口操作。

Ctrl+Z 撤销本次阅读中已保存的高亮、批注或笔记增删改；Ctrl+Shift+Z 或 Ctrl+Y 重做。输入框中保留原生文字撤销，保存草稿并关闭编辑框后再撤销阅读操作。工具栏也有撤销／重做按钮。历史仅保留在当前阅读会话，离开文献或刷新后清空；不撤销翻译请求或文档删除。

选中文字后选择纯高亮或“高亮并附注”。每次选区独立保存，改一个选区的颜色不会改同段其他选区。附注可以修改、定位或删除。

“完成”、Ctrl+Enter 或 Esc 会保存编辑内容。失败时保留草稿，按错误提示重试；导出前确认保存成功。笔记面板还支持独立笔记，可关联段落摘录、页面或整篇文献。页面上的标记可以打开对应笔记。

## 5. 导出与备份

| 格式 | 包含内容 |
| --- | --- |
| 双语 Markdown | 原文和译文，以及笔记／批注内容 |
| 译文／原文 Markdown | 对应正文及阅读记录 |
| 带批注 PDF | 原始页面、高亮、批注标记和可见笔记附录，附录链接返回原文页 |
| JSON | 段落、译文、批注和笔记的结构化数据 |

**PDF 导出不包含浏览器中的译文覆盖层**。需要导出译文时使用 Markdown。部分 PDF 阅读器隐藏弹出式附注，因此请查看文件末尾的可见笔记附录。

JSON 目前没有一键导入恢复界面。完整备份时停止应用，复制整个 data/（或 APP_DATA_DIR），并单独保护 .env。不要把真实文献、数据库、访问令牌或密钥提交到 GitHub。

## 6. 翻译记忆与重新解析

全文翻译会复用相同原文、目标语言和强制术语对应的真实译文，Mock 不写入真实翻译记忆。“强制重翻”跳过复用并请求当前服务，可能产生额外费用。

重新解析会重建段落并清空当前段落译文，保留批注和笔记并按引用尝试重新挂接；相同内容仍可能命中真实翻译记忆。改动原文、术语或识别结果可能需要新的翻译请求，不保证重新解析完全免费。

## 7. 排错与练习

打不开应用时先确认安装和前端构建；翻译失败时核对模型名称、接口、密钥变量和协议。扫描版论文没有完整整页 OCR 管线，局部区域可手动处理。其他问题见 [安装文档](INSTALL.md#常见问题)。

建议在 PDF 说明书上完成：整篇翻译、两次不同颜色的句子高亮、一条页笔记、图片及图注翻译、Markdown 与 PDF 导出。查看附录中的笔记正文，再重新打开文献检查阅读位置。

PDF 中包含工作流程、选句高亮及图片 OCR 三幅示意图。第 2 页展示独立选区颜色和笔记，第 3 页的图片文字可用于“翻译图片与图注”练习。

翻译进度按当前可翻译的文字块统计：正文、标题、列表、图注和表注计入，图片、表格单元格、公式和参考文献不计入。图片内部 OCR 的进度独立显示。补回缺失图注时总数会增加；重新分类为参考文献的旧译文不会计入完成数。更新代码后请重启后端并刷新页面，再点击“继续翻译”补齐新增文字。

维护者更新说明书后，通常重新点文献库的说明书入口导入新版即可。若需要保留已有说明书的文档 ID，可用项目虚拟环境运行 scripts/sync_user_guide.py 加文档 ID；脚本先备份数据库、保留旧 PDF 和完全相同的译文，有笔记或批注时会拒绝替换，避免改变原文定位。

## 8. 平板与镜像站（可选）

把已翻译的文献发布成静态站点后，平板和手机可以脱离家中电脑阅读和批注：运行 `python scripts/publish_site.py` 生成 `site/`，再部署到 Cloudflare Pages。平板上的批注保存在浏览器本地，可以通过“导出 → 平板批注备份”带回电脑，或在配置同步后自动回流。镜像站是只读的，发布内容对拿到链接的人可见；完整步骤和安全边界见[平板镜像站](MIRROR.md)。
